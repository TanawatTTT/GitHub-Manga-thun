## Ep.5 The-Last-Soul

โลกสุดท้าย... คือโลกที่น้องจิ้งจอกไม่เคยกล้าเผชิญ
โลกที่เขาเป็นต้นเหตุของทุกอย่าง
โลกที่เขาหักหลังบอสด้วยมือตัวเอง

เขายืนอยู่หน้าศพของบอสในความทรงจำ
น้ำตาไม่ไหล... เพราะมันถูกเผาจนแห้งไปนานแล้ว

เสียงจากภายในก้องกังวาน:

“อย่าพยายามล้างแค้นเพื่อคนที่นายฆ่าเอง…”
“ถ้าอยาก ‘ไถ่บาป’ จริงๆ… ก็จงเสียสละทั้งหมดเพื่อหยุดวงจรนี้”

และเขาก็เข้าใจ—พลังแห่งโลกคู่ขนานไม่ใช่ของขวัญ
แต่มันคือ “เครื่องมือไถ่โทษ”
ทางรอดเดียวคือ ลบตัวตนของเขาออกจากทุกเส้นทาง
ลบ "เขา" ออกไปจากทุกโลกที่เคยมี

ตอนจบ:
ในจักรวาลที่สงบลง ไม่มีใครจำชื่อ "น้องจิ้งจอก" ได้อีก
บอสกลับมามีชีวิตในโลกหนึ่ง โดยไม่เคยรู้ว่าใครช่วยไว้

แต่ในความเงียบของห้วงมิติหนึ่ง
แสงเงินบางๆ ยังคงส่องสว่าง
เป็นเครื่องเตือนใจว่า มีใครบางคน… เลือกทำสิ่งที่ถูกต้อง
