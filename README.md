## Ep.5 The-Paradox-of-Fire

เปลวไฟสีเงินแผ่กระจายทั่วห้วงมิติ
เมื่อพลังแห่งโลกคู่ขนานไหลผ่านร่าง น้องจิ้งจอกไม่ใช่แค่มนุษย์อีกต่อไป
เขากลายเป็นบางสิ่งที่อยู่เหนือคำจำกัดความของโลกใบนี้

ในแต่ละก้าวที่เดินผ่าน ความจริงของโลกก็เริ่ม ‘สั่นคลอน’
กาลเวลาแตกหักเป็นเสี่ยงๆ จักรวาลซ้อนจักรวาล บิดเบี้ยวรอบตัวเขา

เขาตามหาบอส—ไม่ใช่แค่ในอดีต หรืออนาคต
แต่ใน ‘ทุกความเป็นไปได้’ ที่เคยมีอยู่

“ฉันจะเผาแก๊งสารเลวพวกนั้นในทุกจักรวาล”
เขาพูดกับตัวเองอีกคน ที่กลายเป็นศัตรูในโลกที่พลังครอบงำจิตใจ

และนั่นคือจุดเริ่มของ สงครามข้ามจักรวาล
น้องจิ้งจอกต่อสู้กับตัวเองอีกนับไม่ถ้วน
—กับตัวเขาในโลกที่เลือกล้มเลิก
—ในโลกที่กลายเป็นเทพ
—ในโลกที่กลายเป็นอสูร

แต่ในทุกโลก มีสิ่งหนึ่งที่เหมือนกัน…
"ความเจ็บปวด" ไม่เคยเปลี่ยนไป

และมันคือสิ่งเดียวที่เชื่อมเขาไว้กับความเป็นมนุษย์

ในวินาทีที่ไฟมอดลง เขาได้ยินเสียงเลือนลางของบอส
เสียงนั้นไม่ใช่จากอดีต… แต่มาจากโลกที่ยัง ‘มีโอกาส’
โลกสุดท้าย
